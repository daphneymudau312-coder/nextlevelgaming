Next Level Gaming & Esports Arena
This project is a responsive multi-page website for Next Level Gaming & Esports Arena, a gaming and esports business based in Johannesburg, South Africa. The site showcases the arena, package options, overview information, fee calculator, and contact form.

Responsive design
The website uses a flexible layout with CSS Grid and Flexbox so content stacks properly on desktop, tablet, and mobile devices.

Calculator logic
The fee calculator allows users to:

Select a package
Enter player count
Enter number of hours
View subtotal, discount, VAT, and total amount
The prototype pricing used is:

Casual Gaming: R150 per player per hour
Competitive Gaming: R220 per player per hour
Premium Arena: R300 per player per hour
Discount tiers:

3 to 4 players: 5%
5 to 9 players: 10%
10 or more players: 15%
VAT is applied at 15% after discount.
